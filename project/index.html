About iMotion

iMotion is a browser-based expression-estimation demo that analyzes live faces, uploaded images, and text cues while keeping the experience transparent, quick, and privacy-friendly.

🧠 face-api.js

Run face detection and expression estimation directly in the browser for live and uploaded imagery

📷 Local camera access

Ask for user permission only when needed and release media tracks when the session ends

📝 Lexicon Analysis

Use a local keyword-based sentiment estimate for sentence analysis and label the output as a heuristic
